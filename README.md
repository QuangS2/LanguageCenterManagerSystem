# Language-Center-Manager

## Mô tả
Hệ thống Quản lý Trung tâm Ngoại ngữ hỗ trợ quản lý các khóa học, lớp học và kết quả học tập của học viên.  
Hệ thống được thiết kế để phục vụ nhiều đối tượng như học viên, giáo viên/trợ giảng và quản trị viên.  
Quản trị viên có thể quản lý chương trình đào tạo, lớp học, sĩ số học viên cũng như theo dõi và cập nhật kết quả học tập trong hệ thống.

## Công nghệ sử dụng
- **Backend:** Spring Boot  
- **Frontend:** React  
- **Database:** MySQL  

## Cài đặt và chạy

### Yêu Cầu
- Java 17
- Node.js 18+
- MySQL

### Chạy Backend
Từ backend/

#### Build

mvn clean install

#### Run

mvn spring-boot:run

#### Test

mvn -Dtest=*Test test

### Chạy Frontend
Từ frontend\language_center

#### Build

npm install

#### Run

npm run dev

#### test

npm test
